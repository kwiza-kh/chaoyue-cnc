# 使用说明（面向操作人员）

本说明按实际加工顺序写：**画图 → 选轮廓 → 生成程序 → 校验 → 空走 → 加工**。

## 1. 启动

双击 `chaoyue-cnc.exe`。程序不需要安装，设置保存在 exe 旁边的 `cnc_settings.ini`；删掉这个文件就会恢复默认设置。

界面从上到下是：

- **菜单栏**：文件、绘图、编辑、显示、查询、选项、编程、帮助。
- **工具栏**：新建 / 打开 / 保存、打印预览、图形信息、计算、撤销 / 重做、重画、平移、窗口缩放、显示全部，以及绘图工具。
- **左侧竖条**：选择、删除、复制、镜像、偏移、阵列、移动、旋转、缩放、修剪。
- **右侧竖条**：端点 / 中点 / 圆心 / 交点 / 最近点捕捉，全部捕捉、关闭捕捉、设置。
- **中间深色图板**：绘图区。滚轮缩放，按住中键拖动画布。
- **底部命令栏**：可以直接输入坐标（例如 `20,15`）确定当前点，也可以输入命令名（例如 `line`、`直线`、`foam`）；输入 `?` 查看完整命令表。
- **底部状态栏**：坐标、视图比例、正交 / 极轴 / 对象捕捉 / 网格开关，以及操作提示。

## 2. 画一个零件

1. 在工具栏选择 **矩形**，在图纸上点两个角点；或选择 **圆**，点圆心再点圆上一点。
2. 需要连续轮廓时用 **多段线**：依次点每个节点，最后右键或按回车结束。
3. 画完后可以框选图形，在左侧竖条里做 **偏移 / 阵列 / 镜像 / 旋转 / 缩放 / 修剪**。
4. 画错了按 `Ctrl+Z` 撤销，`Ctrl+Y` 重做。
5. 用 **显示 → 显示全部** 让图形回到屏幕中间。

> 提示：封闭轮廓的首尾点要重合；打开 **端点捕捉** 后再点，能自动对齐已有端点。

## 3. 线切割编程

1. 框选要加工的轮廓。没有选择时，程序会按图上全部图元生成。
2. 菜单 **编程 → 切割编程...**。
3. 设置：
   - **代码类型**：3B 代码 / G 代码 (ISO) / Mach3 G 代码。
   - **补偿方向**：左补偿 / 右补偿 / 不补偿。快走丝常用右补偿（钼丝在轮廓右侧）。
   - **穿丝孔 X / Y**：切割起点；通常放在轮廓外或废料区。
   - **补偿量**：钼丝半径 + 放电间隙，例如 0.09 mm。
   - **零件名**：会写进程序注释和默认文件名。
   - **自动优化轮廓顺序**：建议勾选，减少空走。
4. 点 **生成代码**。程序会显示代码，并给出路径数、切割长度。
5. 点 **校验** 检查程序结构；确认后点 **存盘**。
6. 3B 文件扩展名 `.3b`，ISO / Mach3 文件扩展名 `.iso` / `.tap`。

> 第一次切割前，请用单段模式核对穿丝方向、补偿方向和圆弧转向。不同控制器对 3B 的 `J`、象限字母约定可能不同。

## 4. 泡沫切割（Mach3）

泡沫切割没有穿丝孔，热丝从泡沫边缘进入。程序会自动选择进刀点、安排轮廓顺序，并把结果输出成 Mach3 程序。

1. 画出泡沫零件的轮廓（多段线 / 直线 / 圆弧；圆也可以）。
2. 框选轮廓，菜单 **编程 → 泡沫切割 (Mach3)...**，或按 `F5`。
3. 设置：
   - **切割方式**
     - `两轴 X/Y`：普通平切，热丝上下同一条轨迹。
     - `四轴 X/Y + A/B`：X/Y 是下端导向，A/B 是上端导向，适合斜切 / 锥度。
   - **补偿**：外轮廓（向外）/ 内轮廓（向内）/ 不补偿。泡沫割缝一般按 **割缝宽度的一半** 补偿。
   - **起点 X / Y**：热丝的停放点，通常放在泡沫块左下角外面。
   - **割缝宽**：实际热丝切出的缝宽，例如 0.4 mm。
   - **切割速度**：mm/min，按泡沫和热丝温度调，例如 900。
   - **空走速度**：关丝移动速度，例如 4000。
   - **引入线**：沿轮廓切线方向多走的一小段，例如 3 mm；可减少入口烧痕。
   - **上端 X / 偏移 Y**：仅四轴使用，A/B 相对 X/Y 的固定偏移。
   - **自动排序 + 就近进刀 + 旋转闭合起点**：建议勾选。程序会比较三种排序方案，选空走最短的。
   - **连续切割**：勾选后不同轮廓之间不关丝，直接切过去；不勾选则 `M5` 关丝、`G0` 空走、到下一轮廓再 `M3`。
4. 点 **生成 Mach3 程序**。
5. 在代码窗口 **校验**，确认 `M03 / M05` 成对、每段有 X/Y、圆弧有 I/J。
6. **存盘** 为 `.tap`，拷贝到 Mach3 的 `G-code` 目录。

### Mach3 程序结构

```gcode
%
(CHAOYUE CNC FOAM CUT / MACH3)
(PART 零件名)
(MODE 4-AXIS X Y A B)
(KERF 0.400 MM  COMP 0.200 MM  FEED 900 MM/MIN  LEAD 3.0 MM)
(CUT 989.2 MM  TRAVEL 230.8 MM  EST 1.2 MIN)
(M03 = HOT WIRE ON, M05 = HOT WIRE OFF)
(X/Y = BOTTOM GUIDE, A/B = TOP GUIDE)
G21 G90 G94 G17 G40 G49 G80
G91.1
M05
G00 X... Y... A... B...
M03
G4 P0.3
G01 X... Y... A... B... F900.000
G02/G03 X... Y... A... B... I... J... F900.000
...
M05
G00 X... Y... A... B...
M30
%
```

- `M03` / `M05` 默认接 Mach3 的主轴输出（或你映射的继电器），用来控制热丝电源 / 接触器。
- `G91.1` 表示圆弧圆心 I/J 为相对坐标（Mach3 默认）。如果你的后处理或控制器使用绝对圆心，请改机床设置或删除这一行。
- 四轴的 A/B 需要在 Mach3 里启用并映射到上导向电机；具体见 [MACH3-设置.md](MACH3-设置.md)。

## 5. 校验与空走

1. 在代码窗口点 **校验**，确认没有红色错误。
2. 把程序拷到机床 / Mach3。
3. **断开热丝电源或钼丝**，先空走：
   - 看 X/Y 方向是否正确；
   - 看 A/B 上导向方向是否正确；
   - 看 `M3` 是否在正确的时刻吸合热丝继电器；
   - 看圆弧 `G2/G3` 转向是否正确；
   - 看割缝补偿是否在废料侧。
4. 确认后再接通热丝 / 钼丝，从单段开始加工。

## 6. 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 新建 / 打开 / 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+A` | 全选 |
| `Delete` | 删除选中图元 |
| `F5` | 打开泡沫切割（Mach3） |
| `F7` / `F8` / `F9` / `F10` | 网格 / 正交 / 对象捕捉 / 极轴 |
| `Esc` | 取消当前操作 / 关闭对话框 |
| 滚轮 / 中键拖动 | 缩放 / 平移 |
| `PageUp` / `PageDown` | 代码窗口翻页 |

## 7. 常见问题

- **生成时提示“请先选择要加工的轮廓”**：框选轮廓，或者不要选择直接生成（会使用全部图元）。
- **图形不在屏幕中间**：点 **显示 → 显示全部**。
- **坐标不对**：检查底部命令栏输入的是 `X,Y`，不是 `X Y`；检查单位设置是 mm。
- **泡沫程序没有 A/B**：切割方式选成“两轴 X/Y”了，改成“四轴 X/Y + A/B”。
- **Mach3 报警 “Radius to end of arc differs”**：检查 `G91.1` 和 I/J 模式；本程序输出相对圆心。
- **热丝不吸合**：检查 Mach3 的 M3 输出映射、继电器接线和热丝电源；先用万用表 / 指示灯测试。
- **切割尺寸偏大 / 偏小**：调整割缝宽或补偿方向；先切一个废料试件量尺寸。

## 8. 文件与备份

- 图形文件 `.cnc` 是文本格式，可以直接用记事本打开、备份。
- 程序文件 `.3b` / `.iso` / `.tap` 也是文本格式。
- 设置文件 `cnc_settings.ini` 在 exe 旁边；换电脑时一起拷走即可。
